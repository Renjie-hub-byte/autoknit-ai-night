## 怎么用

**直接双击 `autoknit-ai-night.html`**，用 Chrome / Edge 打开。单文件、离线、图片已内嵌，拷到任何电脑都能放。

| 按键 | 作用 |
|---|---|
| `→` / `PageDown` | 下一页（动画页空格=播放/暂停） |
| `←` / `PageUp` | 上一页 |
| `F` | 全屏 / 退出全屏 |
| `N` | 打开 / 关闭讲稿备注 |
| `T` | 开始 / 暂停 15 分钟倒计时 |
| `R` | 重置倒计时 |
| `O` | 目录（点击跳页） |
| `Esc` | 关闭备注 / 目录 / 看板放大 |
| 鼠标 | 点功能清单 / 验收用例卡片打开表格；点看板截图放大（翻页只用键盘/触屏，点画面不翻页） |
| 触屏 | 左右滑动翻页；动画页点画面=播放/暂停，拖进度条回讲 |

倒计时在右下角：最后 3 分钟变黄，1 分钟变红。第一次翻页会自动开始计时。

## 现场建议

1. 提前 10 分钟打开 HTML，按 `F` 全屏，翻到第 1 页，确认投影比例。
2. 第 2 页（核心思路）是全场的路标：铁板 vs 零件 + 三元桥换梁，建议停一下，让大家记住“零件化”这个词。
3. 第 5 页（椅子 vs 家）和第 11 页（拼图）是给没有工程背景的同事准备的，建议停一下，让大家看图。
4. 第 9 页动画：**提前试播一遍**（点画面播放，30 秒）；讲的时候可随时暂停指着契约卡讲“86 型面板”。
5. 第 10 页是成本账，建议停一下，让听众消化“1/30 + 3 个岗位”这个反直觉的点。
6. 第 11、12 页连着讲“好改、好加”，是一个整体，不要拆开；它们直接接第 9 页动画里的“契约卡”。
7. 第 13、14 页的链接如果有时间就点开，60–90 秒；网络不稳就跳过，不冒险。
8. 第 15 页的 40 分钟 / 116 条用例是全场最具体的“它真的验过”的证据，建议留足时间。
9. 讲稿备注按 `N` 打开，按 `T` 开始计时；最后 3 分钟会变黄提醒。动画页翻页用键盘 ← →（点画面是播放/暂停）。
